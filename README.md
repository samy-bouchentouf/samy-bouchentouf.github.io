## PDF Export

The page is designed to fit on a single A4 page.

For best results:

1. Open the website in Google Chrome or Microsoft Edge.
2. Press `Ctrl + P` (or `Cmd + P` on macOS).
3. Select **Save as PDF**.
4. Use:
   - Paper size: **A4**
   - Scale: **100%**
   - Margins: **Default**
   - Background graphics: **Enabled** (optional)
